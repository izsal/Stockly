# Stockly Documentation Pack

Dokumen ini adalah paket lanjutan setelah PRD Stockly.

## Isi
- `docs/TDD.md` — arsitektur teknis dan keputusan implementasi.
- `docs/DATABASE.md` — rancangan database PostgreSQL dan aturan inventory.
- `docs/DESIGN_SYSTEM.md` — pedoman UI/UX.
- `tasks/TASKS.md` — breakdown milestone dan acceptance criteria.

## Cara menggunakan
1. Gunakan `PRD.md` di root sebagai ringkasan kebutuhan produk yang disepakati.
2. Baca TDD, database design, dan design system.
3. Kerjakan satu milestone pada satu waktu dan jangan memulai milestone berikutnya sebelum pemeriksaan milestone aktif lulus.
4. Verifikasi typecheck, lint, test, dan build sebelum menandai milestone selesai.

Catatan: dokumen ini merupakan spesifikasi awal. Verifikasi kompatibilitas versi package yang dipilih dan dokumentasi resmi sebelum implementasi.
